# Spotify Advanced Music Recommendation Engine 🎵

An industry-grade recommendation system built with Python using **Singular Value Decomposition (SVD) Matrix Factorization** to discover latent musical traits and predict user artist preferences based on streaming history.

## 🚀 How to Run This Project Locally

### 1. Clone the Repository
```bash
git clone [https://github.com/Azeem1027/rhombixtechnologies_task1.git](https://github.com/Azeem1027/rhombixtechnologies_task1.git)
cd rhombixtechnologies_task1

2. Set Up Your Environment
Create a clean virtual environment and install the required dependencies:

Bash
pip install -r requirements.txt
3. Add the Dataset
Because tracking music streaming history generates massive datasets, the raw data is not tracked on GitHub.

Create a folder named data in the root directory.

Place your streaming history CSV file inside it and name it raw_spotify_data.csv.

4. Execute the Pipeline
Open VS Code, select your environment kernel, and run the Jupyter Notebook cells inside notebooks/01_exploration.ipynb sequentially.
